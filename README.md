# Agent Skills

Рабочие скиллы Vaakom для Codex и других совместимых агентов. Эти же файлы используются локально и публикуются на GitHub. Отдельных публикационных копий нет.

| Скилл | Что делает | Требования |
|---|---|---|
| [Dion Secretary](dion-secretary/SKILL.md) | Записывает встречи, расшифровывает локально, готовит протокол с ассистентом или локальной моделью | Windows, Python 3.12+, аудиоустройства; для записи Dion Speaker Helper |
| [MESH Homework](mesh-homework/SKILL.md) | Собирает задания МЭШ за неделю и сохраняет Markdown | Браузерный инструмент, доступ к дневнику, Python; Windows для необязательного хранилища паролей |
| [YouTube Library](youtube-library/SKILL.md) | Импортирует свои плейлисты и лайки через YouTube API или Takeout | Python 3.12+; Windows для OAuth/DPAPI; Ollama для локальной классификации |

## Установка

Клонируйте репозиторий в выбранную рабочую папку. Подключите нужные каталоги с `SKILL.md` через механизм скиллов вашего агента. Если агент поддерживает ссылки на каталоги, используйте их: изменения останутся в одном месте. Конкретный каталог обнаружения зависит от агента.

Настройте каждый выбранный скилл по его инструкции. Примеры `config.example.json` содержат условные значения. Личные настройки храните в `config.json` (Dion) или `config.local.json` (МЭШ, YouTube); они исключены из Git. Для Dion доступен `configure.py`, который создаёт конфиг и не перезаписывает существующий. Подробности: [настройка Dion](dion-secretary/references/setup.md).

Окружения, установленные зависимости, записи, модели и пользовательские выгрузки храните вне репозитория. Указывайте каталоги загрузок и кэша при установке зависимостей. Само подключение скилла не устанавливает аудиодрайверы, модели и браузерные инструменты.

Dion Speaker Helper — отдельное расширение и native host; они не включены в этот репозиторий. Базовая настройка Dion использует Whisper и протокол с ассистентом. GigaAM и голосовая диаризация требуют отдельных установленных компонентов, описанных в настройке Dion. Локальная генерация протоколов включена в исходники и использует настроенную Ollama.

## Проверки

Из корня репозитория выполните:

```text
python -B tests/run_checks.py
```

Проверки используют временные каталоги, синтетические данные и подмену распознавания. Они не записывают звук, не подключаются к аккаунтам и не загружают модели. Они не подтверждают работу конкретного микрофона, браузера или качество распознавания и протокола на реальной встрече.

## Разработка и публикация

Меняйте рабочие исходники, запускайте проверки и просматривайте состав коммита перед отправкой. Для Dion и МЭШ обновляйте версию и журнал изменений согласно их инструкциям. Не добавляйте локальные конфиги, резервные копии, токены, отчёты школьного дневника, записи или содержимое встреч. Новые каталоги скиллов включайте в разрешённый список `.gitignore` намеренно.
