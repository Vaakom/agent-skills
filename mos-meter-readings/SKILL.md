# Показания счётчиков на mos.ru

По умолчанию работай через подключённый Microsoft Edge в профиле пользователя. Для диагностики используй Chrome, когда пользователь его явно указал. Используй открытую вкладку нужной услуги или открой её в выбранном браузере. Если браузер недоступен, проверь его подключение и запуск. Если mos.ru просит войти, передай пользователю вкладку для самостоятельного входа и продолжи после его ответа. Используй действующую сессию пользователя.

- Вода — `https://www.mos.ru/services/pokazaniya-vodi-i-tepla/new/`.
- Электричество — `https://www.mos.ru/pgu2/counters`.

Если mos.ru показывает баннер об использовании cookies, нажми в нём «Принять» и продолжи работу.

В форме воды выбери сохранённую квартиру в разделе «Код плательщика» и нажми «Продолжить». На экране «Передача показаний счетчиков» используй режим «За один месяц» и кнопку «Архив показаний». У воды кнопка «Передать» общая для приборов квартиры, поэтому перед отправкой проверяй, что изменено поле только выбранного прибора. Рекомендованный период, указанный на странице воды, сам по себе не равнозначен блокировке.

В форме электроэнергии раскрой «Номер лицевого счета», выбери сохранённую запись и проверь подставленный номер счётчика. Кнопка «Продолжить» открывает раздел «Показания по счетчикам» с тарифами и кнопкой «Архив показаний». Архив доступен и вне периода передачи. Для сроков используй актуальное сообщение портала.

## Посмотреть счётчики и показания

Для чтения сначала применяй [прямые GET-запросы](references/direct-reads.md). Для электричества получай сохранённые счета и параметры через API профиля, для воды бери код плательщика и номер квартиры из списка в форме. Если ответ неполный, используй форму для получения недостающих сведений.

1. Открой формы запрошенных услуг. Если видны пустые поля, проверь, раскрывается ли список сохранённых записей. Просмотри все доступные записи по квартирам и открой карточки приборов или историю. Если список отсутствует в текущем сеансе, сообщи, какая форма и какой аккаунт видны, и попроси открыть нужную вкладку Edge. Используй данные отображаемого кабинета.
2. Для каждого прибора укажи квартиру, тип (холодная вода, горячая вода или электричество), расположение при наличии и последние цифры номера. Если этих цифр недостаточно для различения, добавь минимальный однозначный признак. Различай прибор и его тарифы или регистры, например Т1, Т2 и Т3.
3. Покажи таблицу с номером для выбора, квартирой, прибором, предыдущим показанием с датой или периодом, показанием за текущий месяц и доступностью передачи. Для электричества подпиши значения по тарифам, для воды укажи единицу, отображаемую порталом. Текущий месяц определяй по Москве и сверяй с периодом начисления, указанным mos.ru. Предыдущее показание — последнее подтверждённое значение до текущего периода. Если портал относит новое показание к другому периоду, подпиши его отдельно.
4. Если история позволяет установить отсутствие показания за текущий месяц, напиши «Не введено». Если история недоступна или период показания неясен, напиши «Не удалось проверить». Черновик, заполняемое поле и статус «в обработке» отражай отдельно от принятого показания.

Для электричества разделяй последнее учтённое показание и последнее переданное клиентом. Если они совпадают, одной записи с указанием источника достаточно. Для проверки нового значения используй последнее учтённое показание того же прибора и тарифа, в том числе снятое сотрудником. При чтении через форму сверяй его в разделе «Предыдущие». Таблица «Архив показаний» может показывать только переданные клиентом записи.

Запрос на просмотр выполняй в режиме чтения. Поддерживай выбор по номеру строки последней таблицы в этом чате или по квартире, типу и окончанию номера. Перед вводом заново сверяй выбранный прибор на портале, поскольку порядок записей может измениться.

## Передать показания одного прибора

Для воды по запросу «через API» используй [порядок отдельной передачи в «Электронном доме»](references/water-write.md). Один запрос записи относится к одному водосчётчику и одному расчётному месяцу. Для электричества используй форму mos.ru. Если пользователь указал конкретный способ передачи, согласуй смену способа с ним.

1. Для передачи нужны команда пользователя, один однозначно выбранный прибор и вручную введённые значения. Если прибор не указан, покажи подходящие варианты для выбора. Если пользователь указал несколько приборов, предложи выбрать один. У многотарифного электросчётчика принимай значения с обозначением тарифов для одного прибора. Если обязательный тариф отсутствует, запроси его значение.
2. Сверь адрес, тип, номер и тарифы с формой. Проверь допустимость передачи по актуальному состоянию услуги и сообщениям для этого прибора. Если период закрыт, сообщи причину и ближайший интервал только при наличии его на портале. Если приём заблокирован по другой причине, например из-за поверки, укажи её отдельно. При закрытом периоде, блокировке или отсутствии возможности изолировать отправку одного прибора остановись до ввода.
3. Проверь значения по единицам, точности и правилам формы, затем примени проверки ниже. Если такие же показания уже приняты за выбранный период, сообщи об этом. Если за этот период уже принято другое значение, уточни, хочет ли пользователь исправить его, и используй доступную на портале процедуру исправления только по его команде.
4. Передай только данные выбранного прибора и сверь их перед отправкой. Если используется форма с общей кнопкой, убедись, что отправляемые изменения относятся только к выбранному прибору. Выполни отправку по явной команде с выбранным прибором и значениями. Передачу показаний веди в рамках услуги учёта. Оплата, изменение профиля и привязок приборов требуют отдельного поручения.
5. Проверь подтверждение приёма или историю и сообщи квартиру, прибор, период, переданные значения и статус портала. Если после отправки ответ пропал или получен неопределённый статус, проверь историю перед любым повтором. Если результат всё ещё неясен, сообщи это и остановись.

### Проверка введённых значений

- Сравни новое значение с последним принятым показанием того же прибора и того же тарифа, включая текущий период, если в нём уже есть принятое значение. Если новое меньше, остановись до ввода и попроси исправить значение. Равное значение проходит проверку прироста, а история определяет, идёт ли речь о повторной передаче. Если прежнее значение не удалось установить, сообщи об этом и остановись до ввода.
- Для каждого положительного прироста используй до шести последних сопоставимых месячных интервалов из архива этого прибора и тарифа. Пропускай отрицательные разности и интервалы, пересекающие замену прибора. Если между последним принятым показанием и целевым месяцем прошло несколько расчётных месяцев, раздели прирост на их число. При сравнении в рамках того же месяца используй один месяц.
- При наличии хотя бы трёх сопоставимых месячных интервалов пометь прирост как необычный, если он в пересчёте на месяц превышает удвоенную медиану этих интервалов. Если медиана равна нулю, любой положительный прирост требует перепроверки. Если интервалов меньше трёх или число месяцев неясно, покажи исходное значение и прирост и попроси сверить положительный прирост с прибором.
- При необычном приросте до ввода покажи последнее значение, новое значение, разницу и обычный месячный прирост, если он рассчитан. Продолжи только после явного подтверждения этого значения или после получения исправленного значения, которое проверяется заново. Ограничения формы mos.ru продолжают действовать.

Пример диалога: «Покажи показания по всем квартирам» → таблица с номерами → «Передай по № 4: Т1 1234, Т2 567». В ответах достаточно кратких названий квартир и различимых окончаний номеров приборов.
