# Changelog

## 0.2.2 - 2026-10-21

- Добавлен обезличенный пример локальных настроек; личный конфиг исключён из Git.
- Предпочтение браузера задаётся текущим запросом и конфигом; разрешения прошлой установки не переносятся.

## 0.2.1 — 2026-10-19

- Закреплено разрешение самостоятельно запускать Edge для работы с дневником, включая обычный запуск приложения, если браузерный инструмент не запускает его сам.

## 0.2.0 — 2026-10-18

- Добавлено локальное окно сохранения учётных данных в Windows Credential Manager; секреты не попадают в файлы скилла или вывод команд.
- Добавлены проверка наличия записи и синтетическая проверка хранилища.
- Автоматическая передача сохранённых данных в браузер ещё не реализована и не проверена.

## 0.1.0 — 2026-10-18

- Создан сборщик домашних заданий МЭШ за неделю с выбором ребёнка и открытием браузера через доступные инструменты.
- Добавлено сохранение Markdown с проверкой дат, полноты и резервными копиями.
- Интерактивный вход и сбор с реального сайта ещё не проверены: в текущей среде нет подключённого браузера.
