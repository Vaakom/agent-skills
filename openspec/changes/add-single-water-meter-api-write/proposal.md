## Зачем

Передавать показание одного водосчётчика без повторной отправки принятого значения соседнего прибора.

## Изменения

- Описать отдельную передачу через API «Электронного дома» в авторизованной сессии.
- Сверять прибор, месяц и статус до и после передачи.
- При отсутствии средства для PUT сообщать об ограничении и использовать отдельную кнопку прибора после согласования способа.
