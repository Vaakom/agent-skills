## Зачем

Свести чтение показаний к прямым запросам в авторизованном Edge и отразить различие между показаниями клиента и замерами поставщика.

## Изменения

- Электричество читается через сохранённые счета из профиля и API истории.
- Вода читается через API после получения кода плательщика и номера квартиры из формы.
- Сводка электричества показывает источник последнего учтённого показания и последнюю передачу клиента.
