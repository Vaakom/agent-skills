## ADDED Requirements

### Requirement: Чтение через API mos.ru

Скилл SHALL читать список приборов и архив через прямые GET-запросы в авторизованном Edge при наличии подтверждённых параметров.

#### Scenario: Сохранённые счета электричества

- **WHEN** пользователь запрашивает показания электричества
- **THEN** скилл получает счета из профиля, сверяет сохранённые приборы и читает архив каждого запрошенного счёта

#### Scenario: Показания воды

- **WHEN** пользователь запрашивает показания воды
- **THEN** скилл берёт сохранённые реквизиты из формы и читает приборы и их архивы через API

#### Scenario: Ответ API неполон

- **WHEN** прямой запрос завершается ошибкой или данных недостаточно для сводки
- **THEN** скилл проверяет недостающие сведения через форму mos.ru и отмечает непроверенные показания

### Requirement: Источник показаний электричества

Скилл SHALL различать последнее учтённое показание и последнюю запись, переданную клиентом, и использовать последнее учтённое для проверки нового значения.

#### Scenario: Последнее показание снял сотрудник

- **WHEN** архив API содержит более свежий замер сотрудника, чем видимая история передачи клиента
- **THEN** скилл показывает обе записи с датами и источниками и сравнивает новое значение с замером сотрудника по тому же прибору и тарифу
